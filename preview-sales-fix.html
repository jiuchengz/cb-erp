商品模块销量列 · 数据源修复预览

cb-erp | 修改文件：server/_handlers/products.ts（后端 GET /products）| 生成时间：2026-08-21

问题根因

导入销售数据只写入 daily_sales 表（销售统计模块读取），而商品模块的「销量」列此前从 sales_order_items 订单明细表聚合。 两张表互不相通，导致：库存能对应（写入了 products.overseas_stock），销售统计有数据，但商品模块销量恒为 0，时间筛选也无效。

修复内容

  • 商品列表接口销量改为从 daily_sales 按商品的 link_id 聚合；
  • 销量口径 = 销售数量 - 退款数量（实际销量），与销售统计模块一致；
  • 时间筛选由「订单创建时间」改为按 sale_date 过滤，商品模块销量筛选正式生效。

验证状态

  • 后端 TypeScript 编译通过（npm run build:api，esbuild 无报错）；
  • 未影响库存、在途、商品基础信息等原有逻辑；
  • 无链接 ID 的商品（历史商品）销量显示 0，符合预期。
