导入规则（负数=退款）

实际销量列处理存储
正数（如 8）记为销售quantity = 8
负数（如 -2）记为退款refund_qty = 2，refund_amount = 2 × 平均售价
0拦截 提示"实际销量不能为 0"—
同一天同一站点同一链接存在多条记录时自动聚合：销售数量相加、退款数量相加，实际销量 = 销售 - 退款。

后端逻辑（daily-sales.ts POST）

// 按 (sale_date, platform, link_id) 聚合：正数=销售数量，负数=退款数量 const keyMap = new Map<string, any>(); for (const r of body.rows) { const key = `${r.sale_date}|${r.platform}|${r.link_id}`; const cur = keyMap.get(key) || { ...quantity: 0, refund_qty: 0, refund_amount: 0, ... }; const q = Number(r.quantity) || 0; if (q > 0) { cur.quantity += q; cur.unit_price = Number(r.unit_price || 0); } else { const rq = -q; cur.refund_qty += rq; cur.refund_amount += rq * Number(r.unit_price || 0); } keyMap.set(key, cur); }
