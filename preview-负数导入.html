销售统计 - 负数销量导入改动预览

涉及文件：src/pages/Sales.vue（前端导入校验）、server/_handlers/daily-sales.ts（后端 schema）

改动说明

项目改动前改动后
负数销量（如 -1，退款/退货） 整行拦截 不导入、不扣减、不计入统计 允许导入 作为扣减项参与合计
销量为 0 拦截（"必须大于 0"） 拦截（提示"不能为 0"，0 无统计意义）
总出单数量 / 总销售额 只累计正数 正负相抵：扣减项减少总量与销售额
环比计算 仅按正数汇总 按净数量汇总，退款多的周期环比会走低
注：upsert 仍按 (sale_date, platform, link_id) 覆盖更新；同一天同一链接重复导入会整体覆盖，不会叠加扣减。

前端校验逻辑（Sales.vue）

// 改动前 if (qty <= 0) { errLines.push(`第${lineNo}行：实际销量必须大于 0`) continue } // 改动后 if (qty === 0) { errLines.push(`第${lineNo}行：实际销量不能为 0`) continue } // 允许负销量：代表退款/退货，导入时扣减

后端 schema（daily-sales.ts）

// 改动前 quantity: z.coerce.number().positive() // 改动后 quantity: z.coerce.number().refine((v) => v !== 0, { message: 'quantity must not be 0' })

导入表现示例

  • 上传 84 条正数 + 4 条负数：84 条正常导入，4 条负数作为扣减项入库
  • 页面"总出单数量"显示净数量（正数合计 + 负数合计）
  • 某链接当天 +10 与 -2 两条记录：该链接出单数量显示 8
